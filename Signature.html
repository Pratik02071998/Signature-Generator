How to Set a Signature in Outlook (Desktop & Web)

Outlook Desktop App (Windows/Mac)

  1. Open Settings:
    • File → Options → Mail → Signatures…
  2. Create Signature:
    • Click New → Name the signature.
    • Copy the generated signature into the Edit Signature box.
  3. Apply Signature:
    • Under Choose default signature, set:
      • Email Account: Select the account.
      • New messages / Replies/forwards: Choose the signature.
  4. Click OK to save your signature settings.

Outlook on the Web (OWA)

  1. Open Settings:
    • Go to https://outlook.office.com/owa/?realm=education.wa.edu.au → Settings (⚙️) → Account →  Signatures
  2. Create Signature:
  3. Apply Signature Automatically:
    • Check the boxes for:
      • New messages I compose
      • Messages I forward or reply to
  4. Save & Test:
    • Click Save → Compose a new email to ensure the signature appears.
